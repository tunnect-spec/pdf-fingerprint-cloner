# 🛡️ PDF Fingerprint & Metadata Cloner (Windows EXE & GUI)

Профессиональное приложение для криминалистического (forensic-level) переноса цифровых отпечатков, метаданных и структуры оригинального PDF-документа на ваш модифицированный файл с **полным сохранением вашего текста и вёрстки**.

---

## 🎯 Какую задачу решает программа?

Когда вы редактируете или генерируете PDF (например, через Word, Chrome, LibreOffice, Canva или онлайн-редакторы), эти программы полностью перезаписывают внутренние метаданные:
* Подменяют поля `Producer` и `Creator` (например, на `Google Chrome`, `Skia/PDF`, `LibreOffice`).
* Генерируют случайные новые Trailer File Identifiers (`/ID [<PermID> <ModID>]`).
* Стирают или меняют исходные UUID цифрового отпечатка в потоке **Adobe XMP** (`xmpMM:DocumentID`, `xmpMM:InstanceID`).
* Сбрасывают дату создания и модификации на текущую.
* Меняют заголовок версии PDF (`%PDF-1.x`).

Любая автоматическая проверка или экспертный анализ документа сразу выявляют подмену.

**PDF Fingerprint Cloner** решает эту проблему:
Вы передаете **Оригинальный PDF** (донор) и **Свой PDF** (с нужным вам текстом). Программа внедряет 100% цифровых отпечатков оригинала в ваш файл, оставляя ваш новый текст неприкосновенным!

---

## ⚡ Что именно переносится из оригинала:

1. **Trailer File Identifier (`/ID`)**:
   - Постоянный ID создания (`PermanentID` `ID[0]`).
   - Модификационный ID (`ChangingID` `ID[1]`).
2. **Сырой поток Adobe XMP Metadata (`/Root /Metadata`)**:
   - Точный XML-пакет без искажения кодировки и пространств имен.
   - `xmpMM:DocumentID` (уникальный UUID документа).
   - `xmpMM:InstanceID` (UUID ревизии).
   - `xmp:CreateDate`, `xmp:ModifyDate`, `xmp:MetadataDate`.
   - `pdf:Producer`, `pdf:PDFVersion`, `xmp:CreatorTool`.
3. **Словарь информации документа (`/Info`)**:
   - `Title`, `Author`, `Subject`, `Keywords`.
   - `Creator` (например, `Adobe InDesign 18.2`).
   - `Producer` (например, `Adobe PDF Library 16.0`).
   - `CreationDate` и `ModDate` (в формате PDF `D:YYYYMMDDHHmmSS...`).
   - Все вендорные и кастомные ключи.
4. **Заголовок версии PDF**:
   - Бинарная сигнатура в начале файла (`%PDF-1.3`, `%PDF-1.4`, `%PDF-1.5`, `%PDF-1.6`, `%PDF-1.7` и бинарный маркер).
5. **Каталог документа (`/Root`)**:
   - `ViewerPreferences` (режим отображения, панели инструментов, подгонка по размеру).
   - `PageLayout` и `PageMode`.
   - `OutputIntents` (профили цветокоррекции ICC, маркеры стандартов PDF/X и PDF/A).
   - `PieceInfo` (служебные данные графических редакторов Adobe Illustrator/Photoshop).
6. **Геометрия страниц (опционально)**:
   - Синхронизация `MediaBox`, `CropBox` и `Rotate`.

## 🚀 Режимы работы

1. **🟢 Умная инъекция (Smart Injection — Рекомендуемый)**:
   - Базой выступает ваш PDF с новым текстом.
   - В него аккуратно пересаживаются все 100% отпечатков и метаданных оригинального файла.
   - Подходит для файлов с любым количеством страниц и шрифтов.
2. **🔵 Вживление в контейнер (Container Grafting)**:
   - Базой выступает оригинальный PDF-файл.
   - Внутренние потоки отображения страниц (`/Contents`) и ресурсы (`/Resources`) заменяются на страницы из вашего PDF.
   - Идеально сохраняет внутреннюю низкоуровневую структуру оригинального PDF.

## 📦 Как получить и запустить `.exe` на Windows

### Способ 1: Сборка в 1 клик на Windows (Рекомендуется)
1. Скачайте/скопируйте папку проекта на ваш компьютер с Windows.
2. Дважды кликните по файлу **`build_exe.bat`** (или запустите `build_exe.ps1`).
3. Скрипт сам создаст виртуальное окружение, установит зависимости и скомпилирует через PyInstaller файл:
   ```
   dist\PDF_Fingerprint_Cloner.exe
   ```
4. Готовый `.exe` файл откроется в проводнике Windows. Это полностью автономный файл, который можно переносить на любую флешку и запускать на любом компьютере без установки Python!

### Способ 2: Облачная сборка через GitHub Actions (Без установки чего-либо)
В проект включен файл `.github/workflows/build_exe.yml`:
1. Загрузите код в любой репозиторий на GitHub.
2. Перейдите во вкладку **Actions**.
3. Запустите workflow **Build Windows EXE**.
4. Через 1 минуту скачайте готовый `PDF_Fingerprint_Cloner.exe` прямо из артефактов GitHub!

### Способ 3: Прямой запуск через Python
Если на компьютере установлен Python:
```bash
pip install -r requirements.txt
python app.py
```

python app.py --orig original.pdf --target my_text.pdf --output result.pdf --mode injection

## 🔍 Инспектор отпечатков в реальном времени

В интерфейс встроен живой инспектор метаданных. При выборе файлов он сразу отображает сравнительную таблицу «До / После»:
* Trailer ID оригинала vs вашего файла vs результата.
* Producer и Creator.
* UUID XMP потока.
* Версию PDF заголовка.
Вы сразу видите 100% подтверждение того, что файл получил оригинальные цифровые отпечатки!
